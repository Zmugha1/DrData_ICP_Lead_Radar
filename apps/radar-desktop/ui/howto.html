How to use this

This tool reads public county records and shows who owns what, when the record was published, and what the record does not say.

It does not predict who will buy. It does not contain phone numbers or email addresses. It does not fill in a missing value with a guess.

Every figure traces to a load run with a source and a date. If you need to know where a number came from, start there.

Blank means the source did not publish a figure. It does not mean zero and it does not mean the tool is broken.

A coverage statement is a stated fact about the source, not a fault in the tool. A gap is something the source does not cover.
